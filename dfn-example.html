Definition Element

Learn how the HTML dfn element identifies a term being defined in a sentence.

The dfn element is an element which is used to set off the defining instance of a term. Now that's a self-contained example!

💡 What does <dfn> do?
The <dfn> element identifies the term being defined in the surrounding text. By default, browsers usually display it in italics. In this example, CSS changes its appearance to bold green text.
